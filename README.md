# ジブンのゼンブを。

このサイトは、サイバーエージェントの皆さまにグリッドシステムの魅力を伝えつつ、その題材として私「小坂脩蔵」の人生を 7 つのチェックポイントに分けて綴ったものです。サイトの組版と絵を測るゲームをもって、その魅力をご紹介しています。

サイト：https://jibun-no-zenbu.pages.dev

## 楽しんでもらうための工夫

本文はスクロールだけで読み進められます。英語に切り替えても読んでいた位置は保たれ、スマホでは画面幅に合わせて組み替えます。

**研究から得たグリッド。** 桜を描いた日本画 3 点を測って得た平均グリッドを、5 列の組版、幕の裂け目、判の配置に使いました。

**文章に沿った動き。** 英語の本文を拭うように日本語へ切り替えます。「グリッドシステムが、大好きです。」の言葉に合わせて紙面に線が現れます。

**絵を測るゲーム。** 「絵を、測る。」では 19 枚から選ばれた 3 枚に 4 本ずつ線を引きます。引いた線から出た平均グリッドを、このサイトの骨格と重ねて見比べられます。

## 制作と確認

ノーコードツールでワイヤーフレームを作り、HTML・CSS・JavaScript で 1 ページのサイトに組み直しました。手元では 1 枚の HTML に組み上げ、そこから公開用に画像と CSS・JavaScript を切り出しています。

色は 紙 `#F2F1EC`・墨 `#1C1B19`・朱 `#E84518` の三色だけです。漢字をゴシック、かなを明朝で混植し、要の語だけを大きく組みました。書体は Google Fonts から 4 つ（Zen Old Mincho・IBM Plex Sans JP・IBM Plex Mono・Marcellus）読み込んでいます。

表示の確認には Playwright を使い、PC 3 つ（1440×900・1920×1080・1280×720）とタブレット・スマホ 2 種の 6 通りを、日本語と英語で開いています。エラーと読み込みの失敗を数え、変更の前後を画素でも比べています。

## リポジトリの中身

| | |
|---|---|
| `style.css` | 組版、配色、画面幅への対応、演出 |
| `script.js` | スクロールの演出、日英の切り替え、チェックポイントの判、ゲームの進行と線の比較 |

コードのそばには、**何が気になって、どう直したか**を残しています。先頭の `v` から始まる番号は直した順の目印なので、番号を追って読んでいただく必要はありません。

文字が崩れ落ちる演出の物理演算には matter.js（MIT）を使っています。`script.js` からは `window.Matter` として呼んでいます。

写真と研究資料の PDF、本文、日英の対照表は入れていません。サイトは選考のためにお渡しするもので、一般に広く公開しないためです。
